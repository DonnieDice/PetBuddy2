# BattlePetUtility

BattlePetUtility is a Retail World of Warcraft addon for battle-pet loadouts,
pet-related action buttons, healing, summoning, and zone tracking.

## Requirements

- World of Warcraft Retail
- RGX-Framework

## Usage

Use `/bpu` to open the options panel.

Install the addon as `BattlePetUtility` in the Retail `Interface/AddOns`
directory alongside RGX-Framework.
